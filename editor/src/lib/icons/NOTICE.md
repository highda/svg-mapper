# Waypoint icon gallery: sources and licences

`gallery.ts` is generated by `editor/scripts/generate-icon-gallery.mjs`. It holds
single-colour SVG path data in a 15 × 15 box. The editor offers these icons for
markers. A map's `map.json` contains only the icons its markers use.

## Mapbox Maki 8.2.0 (CC0 1.0)

Every icon with an id starting with `maki-` is the path data of the Maki icon of
the same name, unchanged except for whitespace.
`exit` is built from Maki's `entrance-alt1`: the door frame is mirrored and the
arrow is moved so that it leaves through the opening.

- Source: <https://github.com/mapbox/maki> (npm `@mapbox/maki@8.2.0`)

CC0 requires no attribution. This notice gives it anyway.

## Badges (`badge-0` … `badge-9`, `badge-a` … `badge-z`)

A disc with a digit or capital letter knocked out. The glyph outlines were
converted to path data from **Liberation Sans Bold** 2.1.5 (digitized data
Copyright (c) 2010 Google Corporation; Copyright (c) 2012 Red Hat, Inc., with
Reserved Font Name Liberation). The font is licensed under the SIL Open Font
License 1.1, <https://openfontlicense.org>. The font software itself is not

to be used without restriction.
